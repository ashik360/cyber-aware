# 🛡️ CyberAware | Game Hub

CyberAware is an interactive **cybersecurity awareness training platform** designed to make learning engaging through short missions, gamified challenges, and progress tracking.  
The project blends **education** with **game mechanics** to help users train, detect, and defend against common cyber threats.

---

## 🚀 Features

### 🎮 Interactive Missions
- **Phishing Trap** – Learn to spot suspicious emails (Timed challenge).
- **Password Forge** – Practice building strong passwords (Skill-based).
- **Malware Radar** – Detect malicious activity online (Timed challenge).
- **Social Shield** – Make smart decisions against social engineering (Decision-based).

### 📚 Training Phases
1. **Orientation** – Get started with the basics.  
2. **Missions** – Play interactive games to reinforce learning.  
3. **Assessment** – Test your knowledge with quizzes.  
4. **Mastery** – Earn badges for achievements.  
5. **Certification** – Unlock proof of completion.  

### ✨ Core Features
- Points & Badges 🏅  
- Leaderboard 📊  
- Timed Challenges ⏱️  
- Progress Tracking 📈
